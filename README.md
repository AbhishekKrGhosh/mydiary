# MyDiary: MERN Stack Web Application

## Overview

This project is a full-stack web application developed using the MERN (MongoDB, Express.js, React.js, Node.js) stack. The application is designed to provide a responsive, user-friendly interface with real-time CRUD operations for managing posts. State management is handled with Redux, ensuring efficient and scalable data handling. Additionally, the application includes a feature for image uploads, enhancing user interaction and content sharing.

## Features

- **Real-time CRUD Operations:**
  - Implemented Create, Read, Update, and Delete operations for posts, with real-time updates reflected across the application.

- **State Management:**
  - Utilizes Redux for centralized state management, ensuring efficient data flow and consistency across the application.

- **Responsive Design:**
  - Built with Material UI to ensure a responsive and visually appealing design across various screen sizes.

- **Image Uploads:**
  - Integrated functionality for users to upload images when creating or updating posts.

## Technology Stack

- **Frontend:** React.js, Redux, Material UI
- **Backend:** Express.js, Node.js
- **Database:** MongoDB (Cloud Version)
- **State Management:** Redux
- **Networking:** Axios for API requests
- **UI/UX:** Responsive design with Material UI

## Installation

1. Clone the repository:

    ```bash
    git clone https://github.com/yourusername/mern-web-app.git
    ```

2. Navigate to the project directory:

    ```bash
    cd mern-web-app
    ```

3. Install dependencies:

    ```bash
    npm install
    ```

4. Start the application:

    ```bash
    npm run start
    ```

## Usage

- **Posts Management:** Create, read, update, and delete posts with real-time updates.
- **Responsive UI:** Enjoy a responsive interface that adapts to any screen size.
- **Image Upload:** Upload images as part of your posts.

## Backend Setup

The backend is built with Express.js and handles API requests for managing posts. To set up the backend:

1. Navigate to the server directory:

    ```bash
    cd server
    ```

2. Install backend dependencies:

    ```bash
    npm install
    ```

3. Start the server:

    ```bash
    npm run start
    ```
